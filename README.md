# Sail Script - 服务器管理脚本

一个简洁实用的服务器管理一键脚本，由 SailData.Cloud 设计。

## 功能特性

### 1. 服务器信息
- **基础信息** - 查看服务器主机名、操作系统、内核版本、运行时间、CPU、内存、磁盘等信息
- **流媒体解锁 & IP质量检测** - 检测流媒体平台解锁情况和IP质量

### 2. 面板安装
- **宝塔面板** - 一键安装宝塔面板
- **1Panel** - 一键安装 1Panel 面板

### 3. 实用工具
- **OpenClaw** - 安装 OpenClaw 工具

### 4. Docker 一键安装
- **Docker 一键安装** - 安装 Docker
- **Docker Compose 一键安装** - 安装 Docker Compose

## 使用方法

### 快速开始

```bash
wget -O sail.sh https://raw.githubusercontent.com/SailDataCloud/SailScript/main/sail.sh && chmod +x sail.sh && ./sail.sh
```

或者使用 curl：

```bash
curl -o sail.sh https://raw.githubusercontent.com/SailDataCloud/SailScript/main/sail.sh && chmod +x sail.sh && ./sail.sh
```

### 直接运行

```bash
bash <(curl -s https://raw.githubusercontent.com/SailDataCloud/SailScript/main/sail.sh)
```
